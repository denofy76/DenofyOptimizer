# DenofyOptimizer

**DenofyOptimizer** — это готовый пак для оптимизации операционной системы Windows 11. Сборка включает в себя набор твиков и скриптов, которые помогают повысить производительность ПК, ускорить загрузку системы и улучшить отклик в играх.

## Ссылки
- **Сайт проекта:** [https://denofy76.github.io/DenofyOptimizer/](https://denofy76.github.io/DenofyOptimizer/)

## Состав пакета
- **DenofyOptimizer** — основная сборка с твиками и скриптами (1.44 ГБ)
- **Проверка ПК** — инструмент для диагностики системы (1.85 ГБ)

## Установка
1. Скачайте архив по ссылке выше.
2. Распакуйте содержимое в любую папку.
3. Пользуйтесь
